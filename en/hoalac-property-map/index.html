The problem

The inventory lives everywhere except where it is needed

Hoa Lac agents currently keep their listings in spreadsheets, Zalo and group chats. The cost lands on the one thing that matters most: time spent with the client.

  • 01
    Fragmented data

    The inventory is split across several files, several chats and several machines.

  • 02
    Constant duplication

    The same plot shows up on several sheets with figures that disagree.

  • 03
    Hard to find the right unit

    Filtering a spreadsheet against a client’s brief is slow and easy to get wrong.

  • 04
    No sense of location

    The coordinates live in the seller’s head, not in the data.

  • 05
    Nothing to show the client

    A row from a spreadsheet does not answer "so where is it?".

  • 06
    One sheet per person

    With no shared source of truth, staying in sync is almost entirely manual.

The solution

Swap the spreadsheet interface for a map

Every property appears at its real position. The map is not a side feature — it is the main working screen.

Before · Spreadsheets & chat

  • Locations recalled from memory
  • Filtering by scrolling and Ctrl+F
  • A private copy per staff member
  • The client has to picture it themselves
→

After · An interactive map

  • The spread of the inventory at a glance
  • Search and filter on the map itself
  • One shared inventory
  • A popup shows where it is and what is next to it
How it is used · Phase 1

Four steps, no manual required

The users run a business; they are not technical. Every action has to be faster than opening a spreadsheet.

01

Marker

Every property is a point at its real coordinates, colour-coded by type.

02

Popup

Tap a marker for the unit code, area, price and status at a glance.

03

Full page

Open the complete record: details, photos and notes.

04

Search & filter

Filter against the client’s brief on the map; results narrow instantly.

Grow deeper rather than wider.

No attempt to build a property platform for the whole of Vietnam. Every bit of effort goes into being the best data platform for Hoa Lac alone.

  • Smallest useful thing firstStart from a minimal version that is genuinely usable.
  • Build only when it is neededA feature has to solve a problem that exists today, not an imagined one.
  • An architecture that scalesThe schema accounts for multi-company from the start, long before it ships.
  • Data is the assetCorrectness, de-duplication and standardisation come before expansion.
Defining success

Four questions every decision is judged against

  • SpeedAn agent finds a property faster than in a spreadsheet.
  • ClarityA client pictures the location without it being explained.
  • One sourceThe inventory lives in one place, with no duplicate copies.
  • HeadroomThe system is ready to serve several companies.
